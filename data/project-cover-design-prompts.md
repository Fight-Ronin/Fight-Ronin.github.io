Method: built-in ImageGen, edit mode. These versions replace the minimal-retouch versions on the website. All source files and earlier versions remain intact.

PRISM preserves the older adult / predictive model / forecast concept while redesigning the layout and title hierarchy. ## PRISM
Source: `images/PD_hospice.png`
Output: `images/PD_hospice-designed.png`

### Final prompt
Use case: style-transfer.
Input image 1: EDIT TARGET, original Parkinson's research illustration.
Request: a clear, substantive DESIGN UPGRADE of this original project picture, retaining its recognizable content rather than inventing a different concept. Landscape 4:3 project thumbnail for an AI researcher portfolio.
Preserve the same three core subjects: friendly elderly bald man with grey side hair and round navy glasses, a simple six-node predictive network, and three ascending bars with a rising arrow. Preserve the warm cream/navy/teal palette and flat editorial illustration character, with a very restrained coral accent on connecting arrows.
Redesign composition: three clean balanced illustrated modules across the middle, older adult on the left, network in center, forecast symbol on right; a thin directional connector in the gaps makes the left-to-right progression unambiguous. Use more refined consistent thin strokes, deliberate aligned baselines, simplified attractive shapes, ample whitespace, subtle flat tonal depth, no enclosing cards. The network should no longer dwarf the person. White/cream paper background, no heavy grain.
Typography upgrade: replace the huge three-line paragraph with a prominent but restrained top-left project name "PRISM", followed by the exact smaller subtitle "6-Month Mortality in PD". No other text. All typography crisp clean sans-serif, navy, generous margins. Main visual fills the central 60 percent. Keep it useful and legible at small thumbnail size.
Invariants: preserve the original story, elderly person identity cues, six network nodes, three bars, arrow, approachable palette. This is a symbolic project illustration, not a plot of findings. Do not add numerical results, axes, medical claims, hospital imagery, brains, prisms, 3D glass, neon, or unrelated objects. The result should feel like the original illustration thoughtfully art-directed into a professional research cover, NOT mere sharpening and NOT a new subject.
